# Bright-Tv-Case-Study
This presentation analyses BrightTV viewership data to identify user behaviour, content performance, and viewing patterns. The insights highlight key drivers of engagement across content types, time of day, and geographic regions, and provide data-driven recommendations to support user growth and increase platform engagement.

# Problem Statement
BrightTV lacks clear visibility into how users interact with content across different regions, time periods, and content types. Without these insights, it becomes difficult to optimize content strategy, improve user engagement, and drive platform growth. BrightTV operates in a highly competitive streaming environment where understanding user behavior is critical for growth and retention. However, the platform currently lacks clear, data-driven visibility into how users interact with its content across different dimensions such as content categories, viewing times, and geographic regions.
Without these insights, key business decisions — including content acquisition, scheduling, and regional targeting — are largely based on assumptions rather than evidence. This creates a risk of underperforming content investments, missed engagement opportunities, and an inability to fully capitalize on high-performing user segments.

# Aim of the Project 
The aim of this project is to conduct a comprehensive analysis of BrightTV’s viewership data in order to uncover meaningful patterns in user behavior, content performance, and viewing trends. This project seeks to transform raw, unstructured data into actionable insights that can guide business decisions and improve overall platform performance. 

# Summary of the Results 
The analysis revealed clear patterns in user engagement based on content type, time of day, and geographic location. Certain content categories consistently performed better, while specific time slots showed peak user activity. Regional differences also influenced viewing preferences.
These insights provide a strong foundation for:
Improving content scheduling
Personalizing user experience
Targeting high-performing regions
Increasing overall platform engagement
